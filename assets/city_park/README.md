# City Park assets

Pasta de runtime destinada aos assets do parque de diversões do City Horizon.

Os assets promovidos para esta pasta devem seguir os contratos visuais e técnicos do projeto (câmera isométrica, escala, transparência RGBA, ausência de halo/fundo embutido, pivôs consistentes e empacotamento compatível com a Engine).

A roda-gigante aprovada será o primeiro asset desta categoria.
