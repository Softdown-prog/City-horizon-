# Retired CH Blender jobs

These 20 historical requests are preserved byte-for-byte for provenance, outside the active execution queue. Their authoring scripts/recipes were deleted or their final review records violate the current gate. `retirement_reasons.json` records each validation failure. No approval or missing authoring source has been fabricated. To rerun an asset, create a new valid preflight/proxy job and obtain actual visual approval before final rendering.
