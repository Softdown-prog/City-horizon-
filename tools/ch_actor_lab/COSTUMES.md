# CH Actor costumes

`CH_ACTOR_COSTUME_V1` adds frame-aligned costume pixels over the approved `ch_actor_green_01` body without changing locomotion, timing, pathfinding or ground anchor.

## Clown pilot (`clown_01`)

The clown costume is generated by `tools/ch_actor_lab/build_clown_costume.py`.

Each approved actor frame gets two matching 48x64 files:

- `frames/<actor-frame>.png`: transparent clown overlay.
- `masks/<actor-frame>.png`: recolor mask for that overlay.

Mask channels:

- R = primary costume color.
- G = secondary costume color.
- B = wig/hair color.
- A = overlay alpha.

The white face makeup, red nose/mouth and blue eye makeup are fixed authored pixels and intentionally stay outside the tint channels so palette swaps do not destroy the clown read at 48x64.

The costume adds a puffy wig, clown makeup, bow tie, colored trouser accents and enlarged shoe accents. The overlay filenames match the 36 approved actor filenames one-for-one, so the existing four directions and eight walk phases remain authoritative.

Run:

```bash
python tools/ch_actor_lab/build_clown_costume.py
```

The generator writes the costume package under `assets/characters/ch_actor_green_01/costumes/clown_01/` and a review board under `tools/ch_actor_lab/art/costumes/`.

## Contract rule

A costume must never rewrite the approved CH Actor body frames. New silhouettes such as wigs, hats, costumes, backpacks or character makeup belong in aligned overlays. Base jacket/trouser recolor may continue to use the existing actor clothing mask alongside the costume overlay.
